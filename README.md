# CV-Jobs

Aplicação Android de Gestão de Estágios e Empregos para Estudantes de Cabo Verde

## 📱 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma aplicação móvel Android destinada a facilitar a ligação entre estudantes, empresas e instituições em Cabo Verde, permitindo a divulgação, candidatura e gestão de vagas de estágios e empregos. A aplicação pretende centralizar as oportunidades profissionais num único sistema digital, reduzindo a dependência de anúncios informais e aumentando a transparência no processo de recrutamento. A aplicação possui três tipos de utilizadores:
- **Aluno (Estudante)**
- **Empresa ou Instituição**
- **Administrador**

## ⚙️ Funcionalidades

### 🎓 Estudante (Aluno)

- Criar conta e autenticar-se no sistema
- Visualizar a lista de vagas disponíveis (estágios e empregos)
- Filtrar vagas por: Curso, Tipo (Estágio/Emprego), Localização
- Ver os detalhes de uma vaga (descrição, requisitos, empresa)
- Candidatar-se a uma vaga (pode enviar o seu CV)
- Visualizar a lista das suas candidaturas
- Acompanhar o estado de cada candidatura: Pendente / Aprovada / Rejeitada
- Editar os seus dados pessoais

### 🏢 Empresa

- Criar conta e autenticar-se, gerir o seu perfil empresarial
- Criar novas vagas de estágio ou emprego
- Visualizar todas as vagas publicadas
- Visualizar os candidatos de cada vaga
- Abrir e visualizar o CV dos candidatos
- Aprovar ou rejeitar candidaturas
- Consultar o histórico de candidaturas processadas

### 🛡️ Administrador

- Visualizar a lista de empresas registadas no sistema
- Visualizar a lista de utilizadores do sistema
- Aprovar ou remover empresas
- Visualizar todas as vagas publicadas no sistema
- Dashboard

## 🛠️ Tecnologias

- **Kotlin** (Android nativo)
- **Firebase Authentication** — autenticação de usuários
- **Firebase Firestore** — banco de dados em tempo real
- **Cloudinary** — armazenamento dos currículos em PDF (upload unsigned via API REST)

## 🚀 Como rodar o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/ailton2831/UniJobs.git
   ```
2. Abra o projeto no **Android Studio**.
3. Crie um projeto no [Firebase Console](https://console.firebase.google.com) e ative:
   - Authentication (método Email/Senha)
   - Firestore Database
4. Baixe o arquivo `google-services.json` do seu projeto Firebase e coloque em `app/google-services.json` (esse arquivo não é versionado no repositório por segurança).
5. Configure as **Regras de Segurança** do Firestore para exigir autenticação (ver seção abaixo).
6. Crie uma conta gratuita no [Cloudinary](https://cloudinary.com) e configure:
   - Um **Upload Preset** do tipo **Unsigned** (Settings → Upload → Upload presets)
   - Anote o **Cloud Name** (aparece no topo do Dashboard) e o nome do preset criado
   - Insira esses dois valores em `Candidato.kt` (constantes `CLOUD_NAME` e `UPLOAD_PRESET`)
7. Sincronize o Gradle e rode o app em um emulador ou dispositivo físico.

### Regras de segurança recomendadas (Firestore)

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```
